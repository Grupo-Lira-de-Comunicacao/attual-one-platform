# ATTUAL ONE Platform MVP

Fundação visual da plataforma SaaS para negócios locais, criada a partir da especificação oficial v1.0.

## Executar localmente

```bash
npm install
npm run dev
```

## Validação

```bash
npm run lint
npm run type-check
npm run build
```

## Escopo desta etapa

- Design system e layout responsivo
- Navegação lateral e cabeçalho
- Dashboard demonstrativo com dados fictícios
- Páginas-base dos módulos solicitados
- Manifesto PWA e service worker básico
- Placeholder de configuração Supabase, sem conexão ativa

As regras de negócio, autenticação e persistência serão implementadas em fases posteriores.
